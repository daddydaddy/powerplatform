# インストール手順

日本語 | [English](./install-guide.en.md)

このガイドでは、Dataverse Bulk Operations ソリューションを Power Platform 環境にインポートする手順を説明します。

## 前提条件

- Dataverse データベースがある Power Platform 環境
- ソリューションをインポートできる環境ロール（環境管理者またはシステム管理者など）
- ソリューション内のフローで使用する Dataverse、Microsoft Entra ID、および HTTP with Microsoft Entra ID コネクタの接続を作成できるユーザー
- 利用するコネクタに必要なライセンスと、テナントでの利用許可

このソリューションはアンマネージドです。まず開発またはテスト環境にインポートしてください。

## インポート前の確認

1. [ソリューションZIP](../solution/OnboardingTraining_1_0_0_1.zip) をダウンロードします。
2. インポート先が本番環境ではないことを確認します。
3. インポートウィザードで接続を割り当てる担当者が、各コネクタの認証に必要な権限を持っていることを確認します。

ZIP内の一意のソリューション名とファイル名は `OnboardingTraining`、ソリューションの表示名は `DataverseBulkOperations` です。

## インポート

1. [Power Apps](https://make.powerapps.com/) を開き、対象環境を選択します。
2. **ソリューション** を開き、**ソリューションのインポート** を選択します。
3. ダウンロードした `OnboardingTraining_1_0_0_1.zip` を選択します。
4. ウィザードに接続参照の設定が表示されたら、対象環境で使用する接続を割り当てます。表示される参照ごとに、コネクタの種類を確認してください。
   - Microsoft Dataverse
   - Microsoft Entra ID
   - HTTP with Microsoft Entra ID（事前承認）
5. インポートを実行し、完了するまで待ちます。失敗した場合はウィザードの詳細を確認し、接続や環境権限を修正してから再試行します。

## インポート後

1. インポートした `DataverseBulkOperations` ソリューションを開きます。
2. 接続参照がすべて有効な接続に割り当てられていることを確認します。
3. フローを開き、接続が対象環境を指していることを確認します。
4. `create_and_update_multiple_sampleAction` の環境URL、作成データ、更新対象IDをセットアップガイドに従って確認します。
5. 削除フローは実行せずに構成を確認します。テーブル全件を削除するため、セットアップと削除対象の確認が完了するまで有効化・実行しないでください。
6. [セットアップガイド](./setup-guide.md)に従い、専用のテスト環境とテストデータで動作を確認します。

## 注意事項

- ソリューションのインポートだけでは、接続の認証や環境固有の設定は完了しません。
- フローが手動トリガーで実行される場合は、フローの実行権限と実行専用ユーザーの接続設定も確認してください。
- アンマネージドソリューションのコンポーネントはインポート先で編集できます。変更の管理方法を決めたうえで運用してください。
