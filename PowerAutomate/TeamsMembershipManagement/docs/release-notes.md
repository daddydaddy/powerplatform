# Version 1.0.0

Release Date: 2026-08-07

## Initial Release

### Features

- Team Set based membership synchronization
- Excel batch processing flow
- SharePoint Forms integration
- Microsoft Graph membership validation
- Automatic group addition
- Automatic group removal

### Included Flows

- Bulk Add Members to Teams Groups by Team Set
- Bulk Add Members to Teams Groups from Forms Responses

### Included Components

- Environment Variables
- Connection References
- Team Set JSON configuration
